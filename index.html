1. 📦 Proxmox VE

💽 Посмотреть диски
lsblk
Показывает все диски и разделы в виде дерева.
Видишь sda, sdb — это физические диски. sda1, sda2 — разделы на них.
✂️ Разметить диск
fdisk /dev/sda
Интерактивная утилита разметки.
Порядок: g — новая GPT-таблица → n — новый раздел → w — записать.
Осторожно: fdisk затрёт данные на диске. Убедись, что выбрал правильный диск.
🧱 Форматировать раздел
mkfs.ext4 /dev/sda1
Создаёт файловую систему EXT4 на разделе sda1.
EXT4 — стандарт для Linux. Надёжно, умеет журналирование.
📁 Смонтировать диск
mkdir /mnt/vmstorage
Создать папку, куда примонтируем диск.
mount /dev/sda1 /mnt/vmstorage
Примонтировать раздел в эту папку.
df -h /mnt/vmstorage
Проверить, что диск появился и сколько места.
🔁 Автозагрузка диска (fstab)
nano /etc/fstab
Добавь строку:
/dev/sda1 /mnt/vmstorage ext4 defaults 0 2
Теперь диск будет монтироваться сам при загрузке.
Ошибка в fstab → система может не загрузиться. Проверяй внимательно.

2. 🐧 Linux (Ubuntu)

👤 Кто я сейчас
whoami
Показывает текущего пользователя.
Если вывело root — ты под админом. Если имя пользователя — обычный юзер.
🌐 Посмотреть IP-адреса
ip a
Показывает все сетевые интерфейсы и их IP.
Ищи строку inet 192.168.x.x — это твой IPv4-адрес.
📂 Файлы в папке
ls -la
Показывает все файлы, включая скрытые (те, что начинаются с точки).
Флаг -l — подробно, -a — включая скрытые.
🔑 Стать root
sudo -i
Переключает на root-пользователя.
Под root можно сломать всё. Используй только когда реально надо.
🔒 Сменить пароль root
passwd root
Задаёт новый пароль для root. Спросит дважды.
Работает и для других пользователей: passwd admin.
💾 Свободное место
df -h
Показывает все диски и сколько на них свободно.
Флаг -h — в человеческих единицах (ГБ, МБ), а не в блоках.
🔄 Принудительная перезагрузка
reboot -f
Перезагружает систему немедленно, без нормального выключения служб.
Флаг -f = force. Может привести к потере данных. Обычно хватает просто reboot.

3. 🔐 GRUB (сброс пароля)

🚪 Войти в редактор GRUB
При загрузке, когда появится меню GRUB, нажми e.
Если меню не появляется — зажми Shift при загрузке или Esc (зависит от системы).
✏️ Изменить строку загрузки
Найди строку, начинающуюся с linux. В конец допиши:
init=/bin/bash
Затем нажми Ctrl+X, чтобы загрузиться.
Это запустит систему сразу в bash от root, минуя пароль.
📂 Размонтировать корень в rw
mount -o remount,rw /
Делает корневую ФС доступной для записи.
Без этого пароль сменить не получится — корень только для чтения.
🔑 Сменить пароль
passwd root
Задаёт новый пароль root.
После смены — exec /sbin/init или перезагрузка.

4. 🌐 Веб-сервер (Nginx)

📥 Установка Nginx
sudo apt install nginx -y
Ставит Nginx и сразу запускает его.
Флаг -y — автоматически отвечать «да» на все вопросы.
✅ Проверить статус
sudo systemctl status nginx
Показывает, работает ли Nginx.
Зелёное active (running) — всё хорошо. Красное — что-то сломано.
🔄 Перезагрузить конфигурацию
sudo systemctl reload nginx
Перечитывает конфиги без остановки сервера.
Reload лучше restart — не рвёт активные соединения.
📝 Редактировать главную страницу
sudo nano /var/www/html/index.html
Открывает главную страницу сайта.
Файл принадлежит root — поэтому нужен sudo, иначе будет «Permission denied».
🔍 Проверить конфиг и логи
sudo nginx -t
Проверяет синтаксис конфигов, ничего не применяя.
sudo tail -f /var/log/nginx/error.log
Смотрит ошибки Nginx в реальном времени.
Полезно, когда сайт не открывается и непонятно почему.

5. 🔌 SSH и доступ

🚪 Подключиться по SSH
ssh pve_danil@192.168.0.112
Подключается к ВМ под пользователем pve_danil.
ssh root@192.168.0.112
Подключается под root (если разрешено).
По умолчанию root-логин по SSH отключён — это правильно с точки зрения безопасности.
🔄 Перезапустить SSH
sudo systemctl restart ssh
Перезапускает SSH-сервер.
Если ты подключён по SSH — текущая сессия не оборвётся, но новые подключения на секунду могут не проходить.
🔑 SSH по ключу
На клиенте сгенерировать ключ:
ssh-keygen -t ed25519 -C "комментарий"
Скопировать публичный ключ на сервер:
ssh-copy-id user@192.168.0.112
После этого вход — без пароля. И можно отключить PasswordAuthentication в sshd_config.

6. ⚠️ Типичные ошибки

🚫 Permission denied (publickey,password)
SSH не пускает — неверный логин, пароль или ключ.
Проверь: имя пользователя, наличие ключа, права на ~/.ssh (700) и authorized_keys (600).
💥 dpkg was interrupted
Установка пакета прервалась (например, выключили питание).
sudo dpkg --configure -a
Завершает настройку прерванных пакетов.
🔤 Иероглифы на сайте
Браузер не знает кодировку и показывает «кракозябры».
Добавь в <head> HTML-файла:
<meta charset="UTF-8">
🚷 Permission denied при записи файла
Пытаешься писать туда, где нужен root.
Либо открывай через sudo nano, либо поменяй владельца:
sudo chown www-data:www-data /var/www/html/index.html
🌐 Сайт не открывается
Что проверить по порядку:
sudo systemctl status nginx
sudo ss -tulpn | grep :80
sudo ufw status
sudo tail -f /var/log/nginx/error.log
Nginx работает? Порт слушается? Фаервол пускает? В логах что?

7. 🌐 Сети простыми словами

📮 IP-адрес — что это?
Уникальный номер устройства в сети. Как номер квартиры — чтобы данные нашли нужную машину.
192.168.1.50
Четыре числа от 0 до 255. Всё.
127.0.0.1 — это «я сам». 192.168.x.x — домашняя сеть.
📏 Маска — что это?
Показывает, где кончается «улица» и начинается «дом». То есть какая часть адреса — сеть, а какая — конкретная машина.
192.168.1.50/24
«/24» значит: первые три числа — сеть, последнее — машина.
Если у соседа тоже 192.168.1.X — вы в одной сети, видитесь напрямую.
🚪 Шлюз — что это?
Это роутер. Через него уходишь в интернет — как через дверь из квартиры на улицу.
ip route | grep default
Покажет шлюз, обычно 192.168.1.1
Сосед — напрямую. Интернет — через шлюз.
📖 DNS — что это?
Переводчик имён. Ты пишешь google.com, DNS говорит: «это 142.250.185.78».
8.8.8.8 · 1.1.1.1
Публичные DNS-серверы.
ping 8.8.8.8 работает, ping google.com — нет. Значит сломан DNS.
🔢 Порт — что это?
IP — адрес дома, порт — номер квартиры. На одном IP много служб, порт говорит, в какую стучаться.
ПортЧто там
22SSH
80сайт (HTTP)
443сайт (HTTPS)
53DNS
3389RDP (Windows)
3000Grafana
9090Prometheus
sudo ss -tulpn
Показать, кто какие порты слушает
🎯 Как всё работает вместе
Открываешь сайт — что происходит по шагам:
DNS дал IP → маска сказала «не моя сеть» → отправил через шлюз → постучался в порт 443. Страница открылась.
